# Implementation Plan

This plan brings AnWa-Solar in line with `AGENTS.md` and then extends it. Each milestone is implemented on its own branch and merged into `main` when the user confirms it is complete; the merge increases the minor version and is tagged (see `AGENTS.md`).

## M1 – Repository rules (`main`, documentation only)

- [x] `AGENTS.md`, `CLAUDE.md` and this plan
- [x] Remove the prompt tooling of the former chat workflow (`prePrompt.md`, `CreatePrompt.py`, its `.gitignore` entries)

## M2 – Project structure and build (`refactor/project-structure`, v0.3.0)

- [x] Target `net11.0-windows`; `global.json` pins the SDK
- [x] `Directory.Build.props` with `<Version>` as the single version source, `TreatWarningsAsErrors`, `EnforceCodeStyleInBuild`; version shown in the main window title and logged at startup
- [x] `Directory.Packages.props` with central package versions (newest stable versions for .NET 11)
- [x] `.editorconfig` and `.gitattributes`
- [x] Split into `src/AnWaSolar.Core`, `src/AnWaSolar.App` and `tests/AnWaSolar.Core.Tests` (xUnit); namespaces match folders
- [x] Checks `dotnet build -warnaserror`, `dotnet test`, `dotnet format --verify-no-changes` pass

## M3 – Calculation core (`feature/calculation-core`, v0.4.0)

- [x] One string calculation in Core that returns a result object (temperature-corrected values, limit checks, allowed module and string ranges, messages); the live results and the report both use it
- [x] Disabled MPPTs are skipped in the report as in the live results
- [x] The report also checks the maximum number of strings per MPPT
- [x] Tests with worked examples from real datasheets for every check
- [x] Tmin and Tmax are cell temperatures (default Tmax 70 °C); optional VMPP temperature coefficient with the PMAX coefficient as fallback

## M4 – Settings and logging (`feature/user-settings`, v0.5.0)

- [x] Parameters and last selection in `%LOCALAPPDATA%\AnWa-Solar\settings.json`, written atomically and debounced; `appsettings.json` keeps only application defaults and is no longer written at runtime
- [x] One-time import of an existing selection from the old `appsettings.json` next to the executable
- [x] File logger serializes concurrent writes
- [x] Remove the committed personal selection from `appsettings.json`

## M5 – Master data robustness (`fix/master-data`, v0.6.0)

- [x] Inverter currents and other datasheet values as decimal numbers
- [x] Invalid entries are skipped individually and reported in the GUI

## M6 – English translation (`refactor/english`, v0.7.0)

- [x] GUI text, log messages, comments and identifiers (for example `Wechselrichter` → `Inverter`)
- [x] Master data property names in English, with a migration of the existing data files and of saved selections
- [x] `README.md` and `CHANGELOG.md` in English; remove the formula experiment from the README

## M7 – Installer and release (`feature/installer`, v0.8.0)

- [x] WiX 5 installer project `installer/AnWaSolar.Installer` with a fixed `UpgradeCode`
- [x] `tools/Build-Installer.ps1`: self-contained win-x64 publish, MSI and SHA-256 in `dist\installer\`
- [x] `docs/DEPLOYMENT.md` with the build recipe and build records
- [x] First release built from its tag in a clean worktree (v0.8.0)

## M8 – App icon and report preview (`feature/report-preview`, v0.9.0)

- [x] Application icon, generated by `tools/New-AppIcon.ps1`, in the executable, the windows and the installer
- [x] Report preview with WebView2 and formula rendering through KaTeX shipped with the application
- [x] All NuGet packages on the newest stable version (checked 2026-11-24; WiX stays on 5 by decision)

## M9 – Dark mode, About window and manual (`feature/theme-about-manual`, v0.10.0)

- [x] Theme System/Light/Dark with a toggle in the top bar, saved in `settings.json`; WebView2 pages follow it
- [x] About window with version, build, runtime, folders, contact and license
- [x] User manual in `docs/manual`, embedded into the executable, shown with WebView2 (page tree, search, links, formulas)

## M10 – Modern user interface (`feature/modern-ui`, v0.11.0)

- [x] Own title bar in all windows (icon, title, window buttons) with an accent line, instead of the Windows title bar
- [x] Main window in two columns: configuration on the left, structured results on the right
- [x] Results per MPPT as cards: status, values at Tmin and Tmax against the effective limits, voltage window, notes
- [x] Overall status and status bar; messages in app-styled dialogs and short confirmations as snackbar
- [x] Selection and parameter dialogs in the same style; manual updated to the new GUI texts

## M11 – AnWa-Soft design library (`feature/design-library`, v0.12.0)

- [x] `AnWaSoft.Design.Wpf` 0.1.0 from the local package feed `D:\Workspace\Claude\Design\packages` (`nuget.config`)
- [x] Palette, title bar window, message dialog and theme service from the library; the own copies are removed
- [x] `Theme.xaml` keeps only AnWa-Solar's window styles and the state bindings of the results
- [x] Installer contains `AnWaSoft.Design.Wpf.dll`

## M12 – Datasheet import (`feature/datasheet-import`, v0.13.0)

- [x] Own master data in `%LOCALAPPDATA%\AnWa-Solar\Data`, merged with the shipped data; an own entry replaces a shipped one with the same manufacturer and model
- [x] PDF datasheet import: text extraction with PdfPig, recognition of module and inverter values, power class or model selection
- [x] Import dialog to check, correct and complete the values; the datasheet is copied to the user data folder
- [x] Datasheet viewer (WebView2) from the selection dialogs and the main window
- [x] Manual page for the import

## M13 – Report export (`feature/report-export`, v0.14.0)

- [x] Report as a single HTML file: formulas rendered, KaTeX style and fonts embedded, light colours, no scripts
- [x] Report as PDF (A4) from the preview with WebView2, header and page numbers
- [x] Export buttons in the report toolbar; manual updated

## M14 – AC side and grid connection (`feature/ac-side`, v0.15.0)

- [x] Inverter AC datasheet values (rated AC power, max. apparent power, rated and max. AC current, phases, grid voltage) in master data and datasheet import
- [x] DC/AC ratio, AC current and grid connection checks with limits set by the user (unbalanced load, system size, feed-in limit)
- [x] Result card and report section

## M15 – Cables and fuses (`feature/cables-fuses`, v0.16.0)

- [x] Module datasheet value max. series fuse rating, with import
- [x] Standard tables (current-carrying capacity, correction factors, conductivity) as shipped data with sources, values given or confirmed by the user
- [x] Cross-section from current-carrying capacity and voltage drop for DC strings and the AC line; string fuses and AC line protection
- [x] Input dialog, result card and report section with formulas

## M16 – Battery storage compatibility (`feature/battery`, v0.17.0)

- [x] Battery master data with datasheet import; inverter battery values (voltage range, charge and discharge current)
- [x] Compatibility check of the battery bank against the hybrid inverter and usable capacity
- [x] Configuration card, result card, report section and manual page

## M17 – Module leads and battery cables (`feature/cables-extended`, v0.18.0)

- [x] Module lead values (cross-section, plus and minus length) in the master data and the datasheet import; the user's default when the datasheet states none
- [x] String cable cross-section chosen by the user or automatic; voltage drop including the module leads
- [x] Battery cables with or without busbar, main cable and fuses; battery cable table values entered at the user's request, unconfirmed until checked
- [x] Cable dialog, result card, report and manual

## M18 – Projects (`feature/projects`, v0.19.0)

- [x] Project file in the user data folder with project data, all entries and copies of the master data entries; automatic saving
- [x] Start dialog: last project preselected (Enter), five most recent projects, new project, other project file; migration of the previous design
- [x] Project card (edit, switch, export) and project data in the report
- [x] ZIP export with the report as PDF, the datasheets and the project file

## M19 – Component series (`feature/component-series`, v0.20.0)

- [x] Master data organised in series (manufacturer, series, datasheet, power classes): one JSON file per series in a folder per kind and manufacturer, shipped and own
- [x] Own single-list files of earlier versions converted into series files
- [x] Datasheet import saves a whole series with the chosen power classes
- [x] Selection by manufacturer, inverter type (derived from phases and battery input), series and power class

## M20 – Component database (`feature/component-database`, v0.21.0)

- [x] Window with a tree of kinds, manufacturers and series and an editor with one column per power class
- [x] Create, change, copy and delete own series and power classes; shipped series are saved as own copies
- [x] Attach and show datasheets; import from the window

## M21 – Settings and German language (`feature/localization`, v0.22.0)

- [x] Settings page: language, theme, projects and export folder, defaults of new projects
- [x] German texts for windows, results and report (`Localization/de.json`), numbers and dates in the language's format; the language applies after a restart
- [x] German user manual in `docs/manual/de`, links checked in both languages

## M22 – Datasheets per language (`feature/datasheet-language`, v1.0.0)
