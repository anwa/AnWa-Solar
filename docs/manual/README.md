# AnWa-Solar Manual

AnWa-Solar helps you design the PV strings of a photovoltaic system. You select an inverter and, for each of its MPPT inputs, a PV module and the number of modules per string and of parallel strings. AnWa-Solar checks the configuration against the inverter limits over the cell temperature range and shows which values are allowed.

- [String Calculation](string-calculation.md): inverter, strings, results and parameters in detail.

- [Battery Storage](battery.md): check a battery bank against the battery input of a hybrid inverter.

- [Troubleshooting](troubleshooting.md): messages and what to do.

## Using this manual

- Select a page in the tree on the left. Links between pages work like in a browser; **Back** (or Alt+Left) returns to the previous page.
- Type at least two characters into **Search manual…** (Ctrl+F) to search all pages. Select a hit to open the page; the first match is highlighted.
- Press **F1** in the main window to open the manual.

> AnWa-Solar estimates voltages and currents from datasheet values. Check every design against the manufacturer documentation and the applicable standards before you install a PV system.
